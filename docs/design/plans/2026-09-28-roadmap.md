# F1 Pixel Cup — the road to the next "wow" version

Written 2026-09-28. Run autonomously, stage by stage. Each stage gets its own spec and plan, is built test-first, reviewed by a fresh reviewer, has **every** finding fixed (minors included), and is merged and pushed. Pushing deploys it live at https://f1-pixel-cup.vercel.app.

## What every stage is held to

- **Real features only.** If the card, HUD, feed or site says something happens, it happens in the game. There are no fantasies.
- **Physically honest, and nothing over the track.** `Render3D.auditScenery` returns 0 on every circuit, and nothing drives through a barrier or a car.
- **Beautiful.** No placeholder-looking art. Visual work is checked in real screenshots at real window sizes, and the view fills any window.
- **Leclerc first, Hamilton second** in showcase content.
- **Proven.** Unit tests plus browser checks in `tools/checks/`. Every new check is shown to fail on the old code.
- **Supabase (accounts, uploads, leaderboards, scoring explainer) stays the final stage.**
